Database schema checklist

  1. Create a Supabase project.
  2. Enable email authentication and confirm your redirect URLs.
  3. Create a business_hub_data table with user_id uuid primary key references auth.users(id), payload jsonb not null default '{}', and updated_at timestamptz not null default now().
  4. Enable RLS and allow authenticated users to select/insert/update only rows where auth.uid() = user_id.
Show SQL schema + row-level security policies
create table if not exists public.business_hub_data (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.business_hub_data enable row level security;
create policy "Users can read own hub data" on public.business_hub_data for select to authenticated using ((select auth.uid()) = user_id);
create policy "Users can insert own hub data" on public.business_hub_data for insert to authenticated with check ((select auth.uid()) = user_id);
create policy "Users can update own hub data" on public.business_hub_data for update to authenticated using ((select auth.uid()) = user_id) with check ((select auth.uid()) = user_id);

Run this SQL in your Supabase SQL Editor. Never disable RLS or expose service-role keys in client-side code. These policies are intentionally limited to each authenticated user.
